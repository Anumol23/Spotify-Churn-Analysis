Spotify Customer Churn Analysis

Customer Churn Analysis using Power BI

Project Overview

This project analyzes Spotify customer churn patterns using Power BI. The objective is to understand customer behavior, identify patterns associated with churn, and generate insights that can support customer retention strategies.

The analysis was performed on a dataset containing 8,000 customer records.

Tools & Technologies

Power BI Power Query DAX CSV

Project Work

  • Cleaned and transformed customer data using Power Query.
  • Analyzed customer churn patterns across different customer and subscription attributes.
  • Created DAX measures to calculate key performance indicators.
  • Developed an interactive Power BI dashboard for customer churn analysis.
  • Examined customer segments and behavioral patterns associated with churn.

Business Insights

  • Identified customer segments with higher churn levels.
  • Examined customer and subscription characteristics associated with churn.
  • The analysis can help identify customers who may be at higher risk of leaving.
  • The findings can support targeted customer retention strategies.
